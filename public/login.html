No sign-up needed. You get a private sandbox with sample transactions, cleared after a day. Sample data only: please don't enter real financial details.

About the assistant: the demo has no AI model, because the model runs locally (Ollama) and isn't available online. It answers common questions about the sample data with built-in rules. Want a real LLM? Copy the project and run it locally with Ollama.

About the AI: the demo assistant runs on a cloud AI model (Anthropic) with a small daily limit, so your questions and a summary of the sample data are sent to its API. Past the limit it uses the built-in assistant. To use your own model, run it locally with Ollama.
